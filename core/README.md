# Rust Core

Начальное переносимое ядро HomeRadar. Оно не зависит от Android и не обращается к камере, Wi-Fi API, сети или файловой системе.

## Проверка

Из корня репозитория:

```bash
cd core
cargo test --workspace
cargo run -p homeradar-core --example synthetic_walk
```

## Реализовано

- `TimestampNs`: монотонная временная метка в наносекундах.
- `Vec2`: локальные двумерные координаты в метрах.
- `Pose2`: позиция, направление и качество отслеживания.
- `WifiObservation`: SSID/BSSID, RSSI, частота, классификация диапазонов 2.4/5/6 GHz и раздельные времена измерения/получения.
- Проверка диапазона RSSI, частоты и порядка временных меток.
- `Trajectory`: построение линии пути, подсчёт длины и разбиение на сегменты при больших паузах или потере tracking.
- Безопасная интерполяция позиции на время Wi-Fi-измерения только между двумя точками одного непрерывного сегмента; экстраполяция и интерполяция через потерю tracking запрещены.
- Группировка индексов по SSID только для отображения; одинаковый SSID не считается доказательством общего роутера или Mesh.
- `build_heatmap`: агрегация реальных измерений по пространственным ячейкам с количеством образцов, средним, минимумом и максимумом RSSI.

## Пока не реализовано

- ARCore camera pose acquisition и передача Android IMU-потока в Core.
- Sensor fusion, VIO/PDR и коррекция дрейфа.
- Интеграция Android scan events с сохранёнными сессиями и Rust Core.
- Полный конвейер привязки scan events к позам и heatmap в приложении.
- Распознавание Mesh и физической идентичности точек доступа.
- SQLite, формат архива `.homeradar`, сериализация.
- UniFFI и Kotlin bindings.
- Экран траектории и визуализация карты в Android-приложении.

## Ограничения первой версии

Heatmap пока агрегирует только ячейки, в которых есть реальные измерения. Она не интерполирует и не заполняет пустые области. RSSI не переводится в расстояние. При потере tracking траектория начинает новый сегмент, а последняя известная координата не записывается как новая позиция.

Зависимости: на текущем этапе используются только стандартная библиотека Rust; это сознательное решение до фиксации формата данных и FFI.
